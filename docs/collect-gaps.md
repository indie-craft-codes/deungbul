# 수집형 카드의 공통 기능: 흔한 것과 틀의 유무

**왜 이 문서인가.** 사용자가 메아리 계약을 해 보고 물었다: "카드는 중복되면 어떻게 해? 합성 같은 게 있어? 대부분 공통적인 기능인데 빠진 게 많네." 틀의 카드(영웅)는 id마다 하나 + 조각 모델이다(`engine/server/game/systems/roster.ts`: 중복은 그 등급의 조각, 조각으로 별, 별이 최대면 각성, 재료로 조각). 그 바깥의 '카드 손질'이 빠져 있었다. 이 문서는 수집형 RPG에서 카드에 흔히 붙는 기능을 모으고 틀과 견준 뒤, 무엇을 넣었고 무엇을 미뤘는지 적는다(2026-11-27, 가지 `feat/card`).

**표시**는 [genre-features.md](genre-features.md)·[screens.md](screens.md)와 같다: [확인] 원문을 읽음, [검색] 검색 요약·2차 출처로만 봄(수치는 패치로 바뀌었을 수 있다), [통념] 그 장르를 해 본 사람이면 아는 모양이나 이번에 원문으로 다시 보지 못함, [추정] 이 문서의 판단.

**한계.** 이번 조사는 검색 몇 번과 기존 조사 문서([genre-features.md](genre-features.md) 2절, [screens.md](screens.md) 2.6·2.7절, [ux-review.md](ux-review.md))를 다시 읽은 것이다. 게임 안의 화면을 직접 보지 못해 '잠금'·'환원'처럼 화면에만 있는 기능은 [통념]이 많다.

## 1. 흔한 기능과 틀의 유무

상태: **있음**(이전부터) · **넣음**(이 가지, 켜는 칸이 있고 기본 꺼짐) · **기초** · **없음**(다음 후보).

| # | 기능 | 어디에 흔한가 (근거) | 틀 | 틀의 칸 |
|---|---|---|---|---|
| C1 | 중복 → 조각·돌파 재료 | 거의 모든 수집형. 원신의 별자리, 스타레일의 성혼, 에픽세븐·서머너즈 워의 재료 [통념] | **있음** | `HeroRarityDef.shards`, `roster.grant` |
| C2 | 조각으로 별(돌파)·각성 | AFK 아레나 승급, 니케 한계 돌파 [통념] | **있음** | `HERO_RULES.starCost`·`awaken` |
| C3 | **넘친 중복 → 다른 재화** | 원신: 별자리가 다 찬 5성의 중복은 '무주의 별빛' 25개(4성 5개), 그 상점에서 육성 재료 [검색: ggrecon·sportskeeda]. 스타레일의 성혼 다 찬 중복 → 재화, 블루 아카이브의 남는 신비 해방 재료 [통념] | **넣음** | `cards.overflow` (아이템으로, 가방 한도까지) |
| C4 | **범용 조각(선택 조각)** | AFK 아레나 '영웅 선택' 조각, 니케 '범용 코어' 류, 블루 아카이브 엘레프 교환 [통념] | **넣음** | 재료 교환 `HERO_RULES.trade`의 `only`(그 등급에만) |
| C5 | 재료로 조각 사기 | 많은 게임의 상점 [통념] | **있음** | `HERO_RULES.trade` |
| C6 | **합성(같은 등급 n → 위 등급 무작위)** | 서머너즈 워 융합(정해진 재료 몬스터를 모아 한 몬스터) [검색: 서머너즈 워 융합 가이드], 에픽세븐의 6성 재료(재료 영웅은 사라진다) [검색: gamepress], AFK 아레나 승급의 신전(같은 진영 재료) [검색: afk.guide·pocketgamer], 많은 하위 수집형의 '합성' [통념] | **넣음** | `cards.fuse`, 확률표 `fuse:<등급>`(단일 원본 `defs/odds.ts`) |
| C7 | **잠금(즐겨찾기)** | 재료로 쓰는 게임이면 거의 모두 있다(실수로 재료로 쓰지 않게) [통념]. 검색으로는 영웅 잠금 원문을 못 찾았다(장비 잠금은 에픽세븐에서 [검색]) | **넣음** | `cards.lock` |
| C8 | **환원·초기화(되돌리기)** | AFK 아레나 '되감기'(레벨 등을 되돌리고 재료를 돌려받음), 니케 동기화기의 슬롯 초기화 [통념, 검색: nikke.gg]. 별·각성은 돌려주지 않는 것이 흔하다 [통념] | **넣음** | `cards.reset.refund` (레벨·기술 레벨만) |
| C9 | **일괄 성장** | 레벨 [×5]·[최대], 한꺼번에 승급 [screens.md 2.6 통념] | **넣음** | `cards.bulk` |
| C10 | 성장 가능 빨간 점 | 거의 모두 [screens.md 2.6] | **있음 → 넓힘** | 격자 칸의 점: 별(이전부터) + 넘친 조각·범용 조각을 더하면 별 |
| C11 | **추천(자동) 편성** | 거의 모두의 편성 화면 [통념], screens.md U6의 '모자라는 것' | **넣음** | `cards.auto` (편성 탭의 단추) |
| C12 | 레벨 공유(공명) | AFK 아레나 공명의 수정(다섯 영웅의 레벨을 나머지가 따른다) [검색: afk.guide], 니케 동기화기(가장 높은 다섯의 가장 낮은 레벨) [검색: nikke.gg·prydwen] | **없음** | 다음 후보: 레벨 셈(`heroStats`)과 저장이 함께 바뀌어 크다 |
| C13 | 교환 상점(천장 포인트) | 니케 골드 마일리지, 블루 아카이브 [genre-features.md 2.2 확인] | **기초** → `feat/d` | 다른 가지(교환 상점)가 맡는다 |
| C14 | 카드 장비 | 거의 모두 [통념] | **있음** | `herogear` 모듈 |
| C15 | 기술 레벨·각성·시너지·진형 | [genre-features.md] | **있음** | `herogrow.ts` |
| C16 | 도감(가진 카드의 보상) | [통념] | **있음** | `codex` 모듈의 `of: 'hero'` |
| C17 | 카드 이야기·호감도(인연) | 블루 아카이브 인연 랭크, 니케 호감도 [통념] | **없음** | 다음 후보: 내용의 칸이 크다 |
| C18 | 장비 비교(지금 → 바꾸면) | [screens.md 2.6] | **없음** | U11의 '모자라는 것' 그대로 |
| C19 | 재료 카드 소모(같은 카드 여러 장을 낱개로 가짐) | 에픽세븐·서머너즈 워 [검색] | **없음(설계상)** | 틀은 id마다 하나 + 조각 모델이다. 낱개 카드 모델은 저장·편성이 바뀌어 하지 않는다 [추정] |

## 2. 넣은 것 (모두 `HERO_RULES.cards`의 칸: 적지 않은 게임은 예전과 글자까지 같다)

| 칸 | 하는 일 | 확인 단계·화면 |
|---|---|---|
| `overflow: { item, rate(등급) }` | 다 키운 카드(별이 최대, 각성이 있으면 각성도 최대)가 받는 조각 하나를 `rate`개의 `item`으로. 뽑기·선택권·상품·합성 어디서 받든 `roster.grant` 한 곳에서. 가방 한도를 넘는 몫은 조각으로 남는다. 남아 있던 조각은 상세의 [바꾸기] | 뽑기 결과의 칸 '조각 25 → 메아리 결정 125', 안내문 `cardOverflow` |
| `trade`의 `only: [등급]` | 범용 조각: 그 등급의 카드에만 쓰는 재료 | 상세의 교환 단추가 그 등급의 카드에만 보인다 |
| `fuse: { need(등급), from?, names? }` | 잠그지 않은 그 등급 카드의 조각 `need`개(다 키운 카드 → 조각이 많은 카드 차례) → 한 단계 위 등급의 카드 하나. 줄 카드는 뽑기 판에 무게가 있는 그 등급의 카드들, 같은 확률. 확률표 `fuse:<등급>`이 공개 페이지·확률 창에 나오고 추첨 기록(종류 `fuse`)에 남는다 | 카드 목록 머리의 '합성' 칸 → 확인 창(쓸 조각, 나올 카드와 확률) → 축하 카드 |
| `reset: { refund }` | 레벨(과 기술 레벨)을 1로, 쓴 값의 `refund`(0~1, 1이면 무료 초기화)를 돌려받는다. 별·각성·조각은 그대로. 잠근 카드는 하지 않는다 | 상세의 [환원] → 확인 창(돌려받을 것) |
| `lock: true` | 잠금. 합성의 재료와 환원에서 빠진다. 저장·개인 상태의 줄 끝에 1(잠근 카드만 줄이 길어진다) | 상세의 [🔒 잠금], 격자의 🔒 |
| `bulk: true` | 레벨 [×5]·[최대까지](값은 한 번에), [별 모두 올리기](그 카드, 목록 머리에서는 모든 카드) | 상세·목록 머리 |
| `auto: true` | 추천 편성: 전투력이 큰 카드부터 편성 크기만큼 | 편성 탭의 단추 |

함께 넓힌 틀의 칸: 상품의 값에 아이템(`GOODS.*.price: { item, n }`, 결정 상점 같은 교환 재료의 상점을 `goods`의 일반 경로로), 확인 창의 일반형(`confirmAsk`: 재화가 아닌 되돌릴 수 없는 일). 쓰는 법은 [making-a-game.md](making-a-game.md) 26절.

## 3. 미룬 것 (다음 후보)

- **레벨 공유(공명)** C12: 흔하고 방치형에서 특히 중요하다. 레벨의 셈(`heroStats`·`heroFull`)이 '내 레벨' 대신 '공유 레벨'을 읽어야 하고, 레벨 업 값·환원이 함께 바뀐다. 이 가지의 범위(연결 몇 줄)를 넘어 미뤘다.
- **인연·호감도** C17, **장비 비교** C18.
- **합성 재료를 고르기**: 지금은 틀이 차례(다 키운 카드 → 조각이 많은 카드)로 고르고 잠금으로만 막는다. 재료를 손으로 고르는 창은 나중.
- **합성의 무게**: 지금은 위 등급의 카드마다 같은 확률이다. 픽업처럼 무게를 주는 칸은 나중.
