# 문서 지도

이 저장소의 문서마다 무엇을 위한 것이고, 누가 읽고, 지금도 맞는지를 적는다. 저장소 전체의 안내는 [../README.md](../README.md).

상태의 뜻:

- **현행**: 코드와 맞춰 둔다. 코드를 고치면 함께 고친다.
- **설계**: 아직 만들지 않은(또는 일부만 만든) 것의 조사·계획. 들어간 부분은 문서 안에 '상태'로 적는다.
- **기록**: 그때의 상태를 남긴 것. 내용은 고치지 않고, 맨 위에 지금 대응하는 문서를 적는다. 그 안의 파일 경로·수·이름은 그때의 것이다.

'마지막 현행화'는 그 문서를 코드와 대조해 고친 마지막 날이다(2026-11-27의 문서 현행화 작업 `feat/docs5` 포함).

## 문서를 고칠 때

- 코드를 고치면 [making-a-game.md](making-a-game.md)와 [framework-status.md](framework-status.md)의 해당 자리를 함께 고친다. 새 묶음을 끝내면 framework-status 맨 위 요약의 줄과 '0. 이어 갈 것'을 고치고, 자세한 기록은 날짜가 붙은 새 절로 더한다.
- making-a-game.md의 코드 울타리 머리에 파일 경로를 적은 조각(```` ```ts games/sample/server/bonfire.ts ````)은 그 파일과 같아야 한다(`npm run test:sample`의 `docs`). 조각을 고치면 예제의 파일도 같게.
- 상대 링크는 실제 파일을 가리켜야 한다. 기록 문서는 내용을 고치지 않는다.
