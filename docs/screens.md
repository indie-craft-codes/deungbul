# 장르별 기본 화면과 흐름 (UI/UX)

## 0. 머리말

**왜 이 문서인가.** [genre-features.md](genre-features.md)는 '어떤 기능(시스템)이 있어야 하나'를 조사했다. 그런데 예제 "메아리 계약"([proof-echopact.md](proof-echopact.md))을 사용자가 폰(아이폰 세로)으로 해 보니 "기본이 덜 됐다": **탑(수집형)에 홈 화면이 없고, 전투·결과 화면이 수집형답지 않고, 폰 HUD가 겹친다.** 기능은 서버에 있는데 그것을 **수집형의 화면 모양과 흐름**으로 보여 주는 부품이 틀에 없다. 이 문서는 장르마다 '사람이 처음 보는 화면'과 '화면 사이의 길'을 조사하고, 틀(`engine/client/hud/`)과 견주어, 틀에 넣을 **장르별 기본 화면 묶음**을 제안한다.

**범위.** 수집형 RPG(블루 아카이브, 니케, 붕괴: 스타레일, AFK 아레나·AFK 저니, 에픽세븐, 세븐나이츠 계열, 서머너즈 워. 원신은 열린 세계라 보조), 모바일 MMORPG(리니지M·리니지2M·오딘·로스트아크 모바일 계열의 자동 사냥 화면), 방치형(AFK 계열, '키우기'류). 그리고 처음 30분(FTUE), 메인 게임 ↔ 다른 모드 전환, 폰 브라우저 특유의 것.

**표시.** genre-features.md 1절과 같다.

| 표시 | 뜻 |
|---|---|
| [확인] | 2026-11-27 이 조사에서 원문(공식 공지·위키·가이드 본문)을 읽어 확인했다 |
| [검색] | 검색 결과의 요약·발췌로만 보았다(원문 전체를 못 읽었거나 2차 출처). 수치는 패치로 바뀌었을 수 있다 |
| [통념] | 그 장르를 해 본 사람이면 널리 아는 모양이지만 이번에 원문으로 다시 확인하지 못했다 |
| [추정] | 이 문서의 판단·설계 제안이다. 사실 주장이 아니다 |

**한계.** 화면 배치는 글보다 그림의 정보라 위키·가이드에 글로 적힌 것이 적다. 몇 곳(Medium의 N3TWORK 카드 공개 글, 스타레일 팬덤 위키, Prydwen 니케)은 자동 읽기를 막아 제목·검색 요약만 보았다. 그래서 배치에 관한 문장은 [통념]이 많다. 틀에 중요한 것은 "정확히 몇 픽셀이냐"보다 **어떤 화면이 있고, 무엇이 어디에서 한 번에 닿느냐**다. 수치(배속이 열리는 단계, 스태미나 회복 간격)는 [확인]·[검색]을 붙였다.

**틀의 지금을 읽은 곳.** `engine/client/hud/*.ts`(머리 주석), `engine/client/style.css`(폰 배치 `@media (pointer: coarse)`·`(max-width: 720px)`·`(max-height: 480px)`), `games/echopact/client/tower.ts`·`echopact.css`, [proof-echopact.md](proof-echopact.md).

## 1. 지금 틀의 화면 부품과 폰 세로의 문제

### 1.1 화면 부품 일람

틀의 화면은 **들판 MMORPG의 HUD 위에 창(panel)을 띄우는 모양** 하나다. 모든 장르가 같은 뼈대(`hud/skeleton.ts`)를 쓰고, 모드는 그 위에서 틀 요소를 감추거나(`hud/modes.ts`) 게임이 창을 붙인다(`hud/shell.ts`의 `mountPanel`).

| 부품 | 파일 | 무엇 |
|---|---|---|
| 내 정보·대상·기술·접속 화면 | `hud/me.ts` | 왼쪽 위 내 정보(이름·레벨·체력·재화), 대상, 오른쪽 아래 기술 단추 |
| 메뉴 창 | `hud/menu.ts`, `hud/menu/*` | 가운데 창 하나에 탭(장비·성장·우편·일일·거래소·길드·순위 + 게임 탭). 탭에 점(`dot`) |
| 수집형 탭 | `hud/collect.ts`, `collectcalc.ts` | 메뉴의 '영웅'·'뽑기'·'편성' 탭, 뽑기 결과 창, 확률표 |
| 영웅 상세 | `hud/herogrow.ts` | 영웅 탭의 '자세히' → 레벨·별·각성·기술·장비 탭, 영웅 장비·강화, 진형·시너지 |
| 단계 막대·단계 탭 | `hud/stagebar.ts` | 가운데 위 막대(1-3, 물결 칸, 남은 적·시간, 자동 진행, 도전·나가기), 큰 글자 '깸/짐 · n초 뒤', 메뉴의 단계 목록 |
| 소탕 | `hud/sweep.ts` | 소탕 단추와 받은 것의 합 창 |
| 돌아왔을 때의 창 | `hud/idleback.ts` | 방치 보상·오프라인 진행을 한 창으로, '받기/나중에' |
| 확률표 | `hud/odds.ts` | 메뉴의 '확률' 탭, 내 추첨 기록 |
| 귀한 재화 확인 | `hud/confirm.ts` | 두 단계 확인(뽑기 단추) |
| 알림 | `hud/notify.ts` | 가운데 알림(banner)·흘러가는 알림(feed)·대화창(log) |
| 모드 | `hud/modes.ts` | '게임 바꾸기' 단추, 모드마다 탭·감출 요소, `body[data-mode]`, 다른 쪽의 위험 알림 |
| 변신 | `hud/morph.ts` | 메뉴의 '변신' 탭(얼굴 그림·능력치·변신 단추) |
| 자동 사냥 | `client/auto.ts` | 자동 사냥 단추(R), 기술·물약 자동 |
| 튜토리얼 | `hud/tutorial.ts` | 아래 가운데 안내 카드, 조건·강조·건너뛰기·다시 보기 |
| 설정 | `hud/settings.ts` | 소리·그래픽·흔들림·글자 크기·단축키·게임 칸·튜토리얼 다시 보기·약관·내 데이터 |
| 공지·점검 | `hud/ops.ts` | 접속 때 공지 창, 흐르는 띠, 점검 카운트다운 |

### 1.2 폰 세로에서 왜 겹치나 (진단)

폰 세로의 지금 배치(`style.css`의 `pointer: coarse`, `max-width: 720px`): 왼쪽 위 내 정보(168px), 오른쪽 위 대화(160~200px, 64px 높이), 그 아래 오른쪽 열(퀘스트·상점, top 150px), 내 정보 아래 가운데 위 자리(`#topmid`: 단계 막대·판 막대), 왼쪽 아래 조이스틱, 오른쪽 아래 기술·단추 줄, 가운데 알림, 그리고 게임의 창(`towerHome`은 top 64px, 높이 `--app-h − 270px`).

- **자리가 '구역'이 아니라 요소마다의 절대 좌표다.** 요소 열 몇 개가 저마다 `top/left/right/bottom`과 미디어 쿼리를 갖는다. 게임이 창을 하나 더하면(탑의 첫 화면, 작은 표시, '게임 바꾸기') 그 창과 틀의 요소가 서로를 모른다. 메아리 계약에서 '게임 바꾸기'가 내 정보 창과 겹쳐 손으로 옮긴 일이 그 증상이다([proof-echopact.md](proof-echopact.md) '확인'). [추정]
- **수집형 화면이 들판 HUD 위에 '창'으로 뜬다.** 상용 수집형의 홈·단계 선택·결과는 **화면 전체를 차지하는 페이지**이고, 그 위에서 HUD(조이스틱·기술·대화·내 정보)는 아예 없다 [통념]. 지금은 탑의 첫 화면 뒤로 3D 장면과 틀 요소 일부가 남고, 무엇을 감출지는 모드의 `hide` 목록에 게임이 하나씩 적는다.
- **'뒤로'가 없다.** 메뉴 창은 닫기(×·Esc)뿐이고, 화면 사이의 쌓임(홈 → 모험 → 장 → 편성 → 전투 → 결과 → 홈)을 아는 곳이 없다. 폰에서는 브라우저의 뒤로 가기(안드로이드의 뒤로 몸짓)가 **페이지를 떠난다** [추정: `popstate`를 쓰는 코드가 없다].
- **엄지가 닿는 곳에 큰 단추가 없다.** 탑의 '다음 도전'은 화면 위쪽(top 64px)에서 시작하는 창 안에 있다. 세로로 한 손에 쥐면 위쪽 1/3은 엄지가 닿기 어렵다(아래 2.1).

## 2. 수집형 RPG의 기본 화면과 흐름

### 2.1 홈(로비)

**공통 모양** [통념] — 블루 아카이브·니케·에픽세븐·서머너즈 워·세븐나이츠 계열이 거의 같다. 원신 계열(열린 세계)은 홈 대신 세계가 첫 화면이고, 오른쪽 위 빠른 단추(편성·뽑기)로 같은 일을 한다. 한 비평은 원신 이후 여러 게임이 '오른쪽 위 빠른 단추(편성·뽑기)'까지 같은 화면을 쓴다고 지적한다 [검색: raiderking.com].

| 자리 | 무엇 | 비고 |
|---|---|---|
| 맨 위 띠 (가로 전체, 높이 약 40~56pt) | 왼쪽: 계정 레벨·이름·초상(누르면 프로필). 오른쪽: **재화 줄** — 스태미나(현재/상한, 회복까지 시간), 골드, 유료 재화(옆에 '+' = 상점 바로 가기). 맨 오른쪽 우편·설정·공지 | 재화는 셋~넷. '+'는 그 재화를 얻는 곳으로 [통념] |
| 가운데 (화면의 절반 이상) | **대표 캐릭터**(사람이 고른 한 명, 움직이는 그림·누르면 대사) | 블루 아카이브는 메모리얼 로비·L2D, 니케는 로비 배경 캐릭터 [통념]. 블루 아카이브 가이드에 '리더 캐릭터가 꼬마 모습으로' 나온다는 말이 있다 [확인: rentry.org/newbaguide] |
| 왼쪽 세로 줄 | 이벤트 배너(넘기는 카드 2~4장), 기간 한정 상점, 출석·패스 | 배너에 남은 기간 [통념] |
| 오른쪽 아래 (엄지 자리) | **큰 진행 단추** — '모험/출격/캠페인'. 그 위에 지금 장·단계('3-7')와 방치형이면 방치 보상 상자(차오르는 막대) | 가장 크고 가장 밝다 [통념] |
| 맨 아래 띠 (5~6칸) | 캐릭터(목록) · 편성 · 뽑기(모집) · 상점 · 임무 · 길드/소셜 | 칸마다 빨간 점 [통념] |

- **AFK 아레나·AFK 저니(방치형 계열)**: 홈 = 방치 캠페인 화면 자체다. 가운데에서 편성이 계속 싸우고, 보물 상자에 방치 보상이 쌓이며(최대 12시간, genre-features 2.2 [확인]), 아래 띠에 '세계 지도·캠페인·영웅·상점' [통념].
- **니케**: 로비의 '전초기지 방어'(Outpost Defense)가 방치 보상이다. 캠페인 5단계를 깰 때마다 전초기지 레벨 +1, '섬멸'(Wipe Out)은 실제 시간 120분 분을 즉시 받고 하루 첫 번은 무료, 보관이 차면 더 쌓이지 않아 자주 들어와 받아야 한다 [검색: siliconera, prydwen]. 단추의 자리는 가이드마다 왼쪽 아래/오른쪽 아래로 엇갈린다(버전 차이) [검색].
- **세로냐 가로냐**: 블루 아카이브·니케·에픽세븐·스타레일은 **가로**, AFK 아레나·AFK 저니(폰)·'키우기'류·많은 방치형은 **세로** [통념]. 우리 사용자는 아이폰 **세로**로 했으므로 세로 기준을 먼저 한다.
- **엄지 닿는 곳**: Hoober의 관찰(2012~2013, 1,333건 중 화면을 만진 780건)에서 한 손 49%, 받쳐 들고 다른 손 36%, 두 손 15% [검색: uxmatters.com]. 한 손으로 쥐면 화면 아래쪽 가운데가 가장 편하고 위쪽 구석이 가장 멀다는 '엄지 구역'이 널리 쓰인다 [통념]. (Hoober 자신이 뒤에 그 그림이 틀렸다고 했다는 2차 보고가 있다 [검색: monterail]: 구역의 경계를 수치로 믿지 말고 '자주 누르는 것은 아래'만 지킨다.)
- **누르는 크기**: Apple HIG 44×44pt, Material 48×48dp가 최소 [통념].

### 2.2 화면 사이의 흐름과 깊이

**표준 길** [통념]:

```
홈 ─▶ 모험(콘텐츠 고르기: 캠페인·일일 던전·탑·PvP)
        └▶ 장 지도(장 1~n, 깸·잠김·별 합계, 장 보상 상자)
             └▶ 단계 정보 창(적 미리보기·권장 전투력·첫 보상/반복 보상·별 조건·소모 스태미나·[소탕 ×1 ×n] [출격])
                  └▶ 편성 확인(지금 편성·전투력·바꾸기·[전투 시작])
                       └▶ 전투(자동·배속·일시정지)
                            └▶ 결과(별·보상·경험치) ─▶ [다음 단계] / [다시] / [홈(장 지도)]
```

- **깊이**: 홈에서 전투까지 누름 3~4번(모험 → 단계 → 출격 → 시작). 자주 하는 사람을 위해 **'이어서' 단추**(홈의 큰 진행 단추가 곧장 '다음 단계의 편성 확인')로 1~2번 [통념]. 메아리 계약의 '다음 도전 1-3'이 이것이다(게임 쪽에 있다).
- **뒤로 가기 규칙** [통념]: 화면마다 왼쪽 위에 '뒤로(<)', 옆에 '홈(집 그림)'. 뒤로는 한 칸, 홈은 바로 홈. 안드로이드 뒤로 키 = 뒤로 단추, 홈에서 누르면 '게임을 끝낼까요?'. **전투 중 뒤로 = 일시정지 창**(바로 나가지 않는다). 창(팝업)이 떠 있으면 뒤로가 창을 먼저 닫는다.
- **결과에서의 다음 길**: '다음 단계'는 바로 그 다음 단계의 **편성 확인 또는 곧바로 전투**로(같은 편성이면 확인을 건너뛰는 게임이 많다) [통념].
- **반복 전투**: 에픽세븐의 '반복 전투'(정한 횟수·스태미나가 떨어질 때까지), 서머너즈 워의 '다시 하기' 반복 [통념]. 에픽세븐은 2022년 '백그라운드 전투'를 예고했다: 반복 전투를 펫에게 맡기고 다른 콘텐츠를 손으로 하며, 그동안 다른 반복 전투는 못 하지만 제작·아레나·영웅 성장은 된다 [검색: 공식 2022 하반기 예고, 2023 로드맵 요약]. 8주년(2026)에 게임을 꺼도 도는 오프라인 위임이 보도됐다 [검색: invenglobal, otakukart].

### 2.5 결과 창

**순서** [통념]: (1) 'VICTORY/깸' 큰 글자와 별이 하나씩 떨어짐(0.3~0.5초 간격, 조건 줄이 옆에서 체크) → (2) 계정 경험치 막대·캐릭터 경험치(레벨 업이면 번쩍) → (3) 보상 칸이 차례로 뒤집힘(귀한 것은 등급 색 빛) → (4) 단추.

| 단추 | 자리 | 언제 |
|---|---|---|
| **다음 단계** | 오른쪽 아래, 가장 큼 | 이긴 때. 다음이 잠겼으면(권장 미달) 그래도 보이되 안내 [통념] |
| 다시 | 가운데 | 언제나(스태미나 표시) |
| 홈/장 지도 | 왼쪽 | 언제나 |
| 소탕 | — | 별 셋이면 단계 창에서. 블루 아카이브: **별 셋(모든 조건)으로 깬 임무만 소탕**, 소탕은 스태미나(AP)를 같은 만큼 쓰고 보상을 즉시 [확인: game8.jp, rentry]. 하드는 하루 3번(유료로 6) [검색] |

**실패 창** [통념]: '패배' + **강해지는 길** 줄 3~4개 — 캐릭터 레벨 올리기, 장비 강화, 편성 바꾸기, 뽑기. 줄마다 그 화면으로 바로 가는 단추. 권장 전투력과 내 전투력의 차. AFK 아레나·세븐나이츠 계열이 이 모양 [통념]. 메아리 계약은 처음 20분 해 보기에서 '1-3에서 지고 1-1만 되풀이'를 보고 탑의 첫 화면에 '메아리 키우기' 안내 한 줄을 넣었다(게임 쪽, [proof-echopact.md](proof-echopact.md)).

### 2.6 카드(캐릭터) 목록과 상세

**목록** [통념]:
- 격자(세로 폰 4~5열, 가로 6~8열), 칸 = 초상 + 등급 테두리 색 + 별 + 레벨 + 속성/역할 아이콘. 갖지 않은 것은 흑백(도감 겸). 편성 중이면 표시.
- **정렬**: 등급·레벨·전투력·별·최근 얻음, 오름/내림. **필터**: 등급·속성·역할·진영. 정렬·필터는 **다음에도 기억**.
- 등급 색: 대개 일반 회색/초록 → 희귀 파랑 → 영웅 보라 → 전설 금/주황 → (그 위) 무지개·붉음 [통념]. 뽑기 연출의 색과 같아야 한다(2.7).
- 빨간 점: 올릴 수 있는 캐릭터(돌파 재료가 다 모였다 등).

**상세 한 화면** [통념]: 왼쪽(가로) 또는 위(세로)에 큰 그림, 옆/아래에 탭: **성장**(레벨 막대·[레벨 업]·[×5]·[최대]), **돌파/별**(재료 n/m), **스킬**(스킬마다 레벨·설명·올리기), **장비**(칸 4~6, 끼기·바꾸기·자동 장착), **이야기/프로필**. 맨 위에 전투력과 '이전·다음 캐릭터' 넘기기(좌우 밀기). **비교**: 장비를 바꿀 때 '지금 → 바꾸면'의 능력치 차(초록 +/빨강 −) [통념].

### 2.7 뽑기 연출과 교환 상점

**연출 순서** [통념, 일부 검색]:
1. 배너 화면: 큰 그림, 픽업 캐릭터, 남은 기간, 천장 진행(n/90), [1번] [10번] 단추(값 표시), 확률·기록 링크(genre-features 2.2: 확률 표시 의무).
2. 확인(귀한 재화: 우리 틀 `confirm.ts`).
3. **예고 단계**: 문·별똥별·상자 따위가 열리며 **가장 높은 등급의 색이 먼저 비친다**(금색·무지개). 스타레일의 '워프' 연출은 비평가에게 "이렇게까지 멋질 일인가"라는 말을 들을 만큼 공을 들였다 [검색: pcgamer]. 다른 게임도 상자·오라 색(무지개 = 최고, 금 = 그다음)으로 등급을 미리 알린다 [검색: gamewith(건담 UCE·섀도버스)].
4. **한 장씩 공개**: 낮은 등급은 빠르게, 높은 등급은 멈춰 서서 캐릭터 소개 장면. **새 캐릭터는 'NEW' 표시**와 소개 장면, 중복은 '조각/재료로 바뀜' 표시.
5. **10연 요약**: 열 칸 격자, 높은 등급 빛, NEW 표시, 중복의 전환 결과. [확인/닫기] [한 번 더 10번] [통념]. 여러 게임이 동영상 뒤에 전체 요약을 보인다 [검색: game8 건담 UCE].
6. **건너뛰기**: 오른쪽 위 '건너뛰기(SKIP)' — 남은 공개를 모두 건너 요약으로. 많은 사람이 흔한 뽑기는 건너뛰지만 기다리던 배너에서는 건너뛰지 않는다 [검색: hostedgg]. 건너뛰어도 **새 캐릭터·최고 등급은 한 번 멈추는** 게임이 많다 [통념].

**교환 상점(천장 포인트)**: 니케 골드 마일리지 200 → 픽업 교환, 블루 아카이브 구 방식 200포인트 교환(genre-features 2.2 [확인]). 화면은 배너 화면 안의 '교환' 단추 → 교환할 수 있는 캐릭터 목록·포인트 n/200·기간 끝 때 포인트가 어떻게 되는지 [통념]. AFK 저니는 튜토리얼 안에서 '전체 모집' 30번으로 위시리스트를 연다 [검색: prydwen].

### 2.8 스태미나(행동력)

| 게임 | 회복 | 상한 넘침 |
|---|---|---|
| 원신 레진 | 8분에 1, 상한 200 | genre-features 2.2 [확인] |
| 블루 아카이브 AP | 6분에 1 [검색: game8.jp]. 카페 등급이 하루 AP 회복을 늘린다 [확인: rentry] | 상한 999까지는 쌓이고 넘는 몫은 우편으로 [확인: rentry]. 하루 3번 90 청휘석으로 충전 [확인: rentry] |
| 서머너즈 워 에너지 | 5분에 1 [검색: fandom] | 소셜 포인트 500 → 에너지 20 [검색: fandom] |

**표시** [통념]: 맨 위 재화 줄에 '번개 그림 87/120', 누르면 '다음 1까지 4:12 · 가득까지 3:20:00'. 레벨 업이 상한만큼 채워 주는 게임이 많다(블루 아카이브: 레벨 업 때 새 상한만큼 더해 준다 [확인: rentry]). **부족할 때**: 출격 단추를 누르면 창 — '행동력이 모자랍니다: 물약 쓰기(가진 수) / 유료 재화로 충전(남은 횟수) / 다음 회복까지 n분'. 방치형(AFK)은 캠페인에 스태미나가 없고 방치 보상과 빠른 보상이 그 몫을 한다 [통념].

### 2.9 알림 점(빨간 점)과 임무·우편·출석

- **규칙** [통념]: 점은 '지금 누르면 받을 것/할 수 있는 것'만. **나무 모양으로 위로 번진다**(카드 하나가 돌파 가능 → 캐릭터 탭 → 홈의 캐릭터 단추). 숫자 점은 우편·친구 요청처럼 셀 수 있는 것만. 들어가서 할 일을 하면 **바로 꺼진다**.
- **잘못 쓴 예** [확인/검색]: 빨간 점이 넘치면 사람은 '빨간 점 실명'에 빠져 무시한다, 낮은 중요도는 어두운 점 등 덜 눈에 띄는 표시로 [검색: braze]. 점의 숫자는 그것을 풀어 주는 화면과 **같은 원천**에서 세야 한다 [검색: dolfy]. EA FC 모바일에서 할 일을 다 해도 점이 남아 불만 [검색: EA 포럼]. 점이 무슨 종류인지 모르겠다는 불만(대화 vs 다른 것) [검색: minecraft 의견]. 중국 모바일 게임에서는 빨간 점이 '볼 만한 것'으로 읽힌다는 의견 [검색].
- **진입점** [통념]: 우편(맨 위 오른쪽 봉투), 임무(아래 띠 또는 홈 왼쪽: 일일·주간·업적 탭, '모두 받기'), 출석(접속 때 저절로 뜨는 창 한 번 + 홈 왼쪽 배너), 공지(접속 때 창, 오늘 하루 보지 않기).

### 2.10 방치 보상과 빠른 보상

AFK 아레나: 방치 보상 최대 12시간, 빠른 보상 하루 1번 무료(2시간 분), 뒤로 50 → 80 → 100 다이아(genre-features 2.2 [확인]). 니케 섬멸 120분 분·하루 첫 번 무료 [검색]. **화면** [통념]: 홈(캠페인) 가운데 아래 보물 상자 + 차오르는 막대·'n시간 n분/12시간', 누르면 받은 것 창(골드·경험치·드롭 칸)과 [받기] [빠른 보상]. 접속 때 '자리를 비운 동안' 창.

```
│(조이스틱)                     [물약 n][귀환]       [스킬] [ 공격 ]  │

└────────────────────────────────────────────────────────────────────┘
```

- 자동 사냥 단추는 오른쪽 아래 공격 단추 곁, 켜지면 둘레가 돌거나 글자가 'AUTO'로 빛난다. 오딘은 파티 사냥 때 자동 단추 옆 '+'로 세 가지 모드 중 하나를 고른다 [검색: 인벤 오딘]. 방치 모드에서 가방이 가득 차면 그 뒤로 아이템을 줍지 못한다 [검색: 인벤 오딘].
- 사냥 범위(제자리/주변/맵 전체)·대상(선공 몹 우선 등)을 자동 단추 길게 누르기나 설정에서 고른다 [통념].

### 3.2 물약 자동·귀환 설정 창 [통념]

| 칸 | 흔한 값 |
|---|---|
| 체력 물약 자동 | 켬/끔, 체력 n% 아래에서(밀대 10~90%) |
| 마나 물약 | 같은 모양 |
| 물약이 떨어지면 | 마을로 귀환 / 멈춤 / 그대로 |
| 체력이 n% 아래(물약 없음) | 귀환 주문서 자동 사용 |
| 가방이 가득 차면 | 귀환·판매·멈춤 |
| 죽으면 | 마을에서 다시(자동 사냥 끝) / 그 자리로 돌아가기 |
| 자동 구매 | 마을로 귀환하면 물약 n개 자동 구매 후 사냥터로 |

리니지M 계열 블로그는 자동 사냥을 오래 하려면 물약을 미리 사 두라고, 물약이 떨어지면 체력이 0이 되고 사냥이 멈춘다고 한다 [검색: wikidocs]. 자리를 비울 땐 전투력보다 한 단계 낮은 사냥터를 권한다 [검색: 같은 글]. 메아리 계약의 안전장치(물약 45% · 물러남 25% · 물약이 떨어지면 멈춤 · 쓰러지면 끝)가 이 창의 핵심 넷이다 ([proof-echopact.md](proof-echopact.md)).

### 3.3 절전 모드 [통념, 일부 검색]

- 자동 사냥 중 **화면을 검게** 덮고 밝기를 낮춰 전지·발열을 줄인다. 위에 '절전 중', 가운데에 **지금까지 얻은 것**(경험치 +n%, 골드, 주운 아이템 줄·귀한 등급 색), 체력 막대·남은 물약·가방 칸, 시각. 밀어서 풀기(잠금 그림을 밀기).
- 들어가는 법: 절전 단추, 또는 아무것도 누르지 않은 지 n분 뒤 저절로. 어느 게임(다크 슬레이어)은 기본 10분 무입력이면 저절로, 잠금 그림을 밀어 푼다 [검색: withhive 공지].
- 밤새 돌릴 때 밝기를 낮추라는 가이드 [검색: bittopup].
- **죽음 알림**: 앱은 푸시 권한으로 사망·가방 가득·물약 소진을 알린다(오딘 앱 설명: 알림 권한은 푸시와 기타 알림을 받는 데 쓴다 [검색: 앱스토어]. 알림의 종류는 [통념]). 웹은 iOS 16.4부터 홈 화면에 더한 웹 앱만 푸시를 받는다(genre-features 6절 [확인]).

### 3.4 퀘스트 추적·대화 축소 [통념]

- 퀘스트 추적 창: 왼쪽(가로) 미니맵 아래, 주 임무 한 줄(누르면 자동 이동 = '퀘스트 자동 진행'), 일일·반복 2~3줄, 접기 단추.
- 대화: 기본은 **두 줄로 접힘**(마지막 말만), 누르면 반투명 큰 창(탭: 전체·서버·길드·파티·귓말). 시스템 줄(획득·처치)은 따로 걸러 보기.
- 큰 일(보스 출현·공성)은 맨 위 가운데 흐르는 띠.

## 5. 처음 30분 (FTUE)

**흔한 차례** [통념, 일부 검색]:

| 시점 | 무엇 | 사례 |
|---|---|---|
| 0~1분 | 로고 → (약관 동의) → **곧바로 첫 전투**(강한 캐릭터를 빌려 쓰는 프롤로그) | 스타레일·에픽세븐 프롤로그 [통념] |
| 1~3분 | 이름 짓기(무작위 단추 있음), 짧은 이야기 | [통념] |
| 3~8분 | 1-1~1-3: 자동 없이 손으로 한두 판(스킬 쓰기를 가르침), 결과 창·별 설명 | [통념] |
| 5~10분 | **첫 뽑기(보장)**: 튜토리얼 뽑기는 무료·고정 또는 높은 등급 보장. 다시 뽑기(리세마라)를 허락하는 게임도 | 퍼니싱: 그레이 레이븐 튜토리얼은 S급 확정 배너로 이끈다, 몽길: 스타 다이브 튜토리얼 10연은 4성 하나 보장 [검색: fandomspot, tychara] |
| 8~12분 | **첫 편성**: 새 캐릭터를 편성에 넣는 강제 안내(손가락 그림), 전투력이 오르는 것을 보임 | [통념] |
| 10~20분 | 레벨 업·장비 끼기 안내, **자동 전투 열림**, 배속 열림 | AFK 아레나 ×2는 2-16(또는 VIP 2) [검색]. 스타레일 자동·2배속은 첫 시뮬레이션 우주 뒤 [검색] |
| 15~30분 | 임무·우편·출석이 차례로 열리며 보상 받기 안내, 방치 보상 첫 받기 | AFK 저니: 꿈의 영역은 AFK 단계 16, 아레나는 단계 20(대개 처음 몇 시간) [검색: talkandroid] |
| 30분~ | PvP·길드·일일 던전: '○○를 깨면 열림' 자물쇠 그림을 홈에 미리 보인다 | [통념] |

- **강제와 건너뛰기** [통념]: 처음 5~10분(첫 전투·첫 뽑기·첫 편성)은 **강제**(다른 곳을 누를 수 없고 손가락 그림만), 그 뒤 안내는 건너뛸 수 있다. 기능이 열릴 때마다 '새 기능' 창 한 장 + 그 단추에 빛. 웹 포털은 메뉴 최소·즉시 게임 안으로·컷신 건너뛰기를 요구한다(genre-features 6절 [확인]).
- **열림 계단**: 기능을 단계 수(또는 계정 레벨)로 하나씩 열어 처음 화면의 단추 수를 줄인다(홈의 단추가 처음엔 셋, 30분 뒤 여덟) [통념]. 틀에는 genre-features의 f4 '해금 계단'(없음)이 이것이다.
- 메아리 계약의 지금: 튜토리얼 일곱 단계(1-1 도전 → 뽑기 → '울림골 가기' → 걷기 → 공격 → 변신 → 자동 사냥). 첫 뽑기 1분, 첫 10번 뽑기 18~19분([proof-echopact.md](proof-echopact.md)). 수집형 표준과 견주면 **이름 짓기·첫 편성 안내·결과 창 설명·기능이 열리는 순간의 창**이 없고, 처음부터 탭이 일곱 개 다 보인다.

## 6. 메인 게임 ↔ 다른 모드 전환의 사례

| 사례 | 자리를 비운 쪽의 표시 | 전환 단추 | 위험 알림 |
|---|---|---|---|
| 에픽세븐 백그라운드 전투 | 반복 전투를 펫에게 맡긴 채 다른 콘텐츠를 손으로 한다 [검색: 공식 예고]. 진행 표시는 [통념]: 화면 구석의 작은 펫 그림과 'n/m회' | 반복 전투 창의 '백그라운드로' | 끝나면 결과 요약 창(얻은 것 합) [통념] |
| 니케 전초기지 | 로비에서 보관 막대(시간)·분당 얻는 양 [검색: siliconera] | 로비의 전초기지 단추 | 보관이 가득 차면 더 쌓이지 않음 [검색] |

| 한국형 MMORPG 방치·절전 | 절전 화면의 얻은 것 요약 [통념] | 밀어서 풀기 | 푸시: 사망·가방 가득·물약 소진 [통념] |
| 수집형의 탐사·파견 | 파견 목록에 남은 시간 막대, 끝나면 '완료' 빨간 점 [통념] | 홈의 파견 단추 | 위험 없음(실패가 없는 게 보통) [통념] |
| 원신 탐사 파견 | 캐릭터를 지역에 보내고 n시간 뒤 보상 [통념] | 모험가 길드 NPC | — |

**공통 모양** [추정]: (1) 다른 쪽은 **작은 상태 줄 하나**(무엇을 · 얼마나 · 얻은 것), 누르면 그쪽으로. (2) 위험은 **가운데 알림 + 바로 가기 단추**, 그리고 다른 쪽 단추에 빨간 점. (3) 돌아오면 **'자리를 비운 동안' 요약 창**. 메아리 계약은 (1)·(2)를 이미 했다(`modes.ts`의 위험 알림 + 게임의 작은 표시). (3)은 접속을 끊었다 온 때만(`idleback.ts`) 있고 **모드를 바꿔 돌아올 때는 없다**.

- 전환 단추의 자리: 상용 사례는 홈의 큰 단추 하나(모험/전초기지)이거나 HUD 구석의 작은 상태 줄이다 [통념]. 지금 메아리 계약은 폰에서 '게임 바꾸기'를 왼쪽 아래(조이스틱 자리 근처)로 옮겼다. 세로 수집형 화면에서는 **맨 아래 띠의 한 칸**이 자연스럽다 [추정].

## 7. 웹(폰 브라우저) 특유의 것

| 주제 | 사실 | 틀의 지금 | 할 일 [추정] |
|---|---|---|---|
| 주소창과 높이 | 폰 브라우저는 주소창·도구 막대가 나타나고 사라지며 높이가 바뀐다. `svh`(막대가 펼쳐진 가장 작은 높이)·`lvh`(접힌 가장 큰 높이)·`dvh`(지금 높이) 단위가 이것을 다룬다 [검색: web.dev] | `html, body { height: 100% }`, `#view`는 `position: fixed; inset: 0`, `main.ts`가 실제 높이를 재어 `--app-h`로 둔다 | 화면 페이지(9절)는 `--app-h`(또는 `100dvh`)를 쓰고, 아래 띠는 `svh` 기준으로 주소창에 가리지 않게 |

| 화면 회전 | 웹은 방향을 잠글 수 없다(`screen.orientation.lock`은 전체 화면에서만, 아이폰은 없음) [통념] | `orientation.lock`은 늘 false, `orientationchange`에 다시 잼 | 모드마다 '권하는 방향'(탑 = 세로, 울림골 = 가로도 됨)과, 맞지 않으면 '돌려 주세요' 얇은 띠(막지는 않는다) |

| 뒤로 가기 | 안드로이드 뒤로 몸짓·브라우저 뒤로 = 페이지 떠남 [통념] | 다루지 않음 | 화면 쌓임을 `history.pushState`로 적고 `popstate`를 '한 칸 뒤로'로. 맨 아래(홈)에서는 떠남 확인 |
| 당겨서 새로고침 | 세로 스크롤 목록을 위로 당기면 페이지가 새로고침될 수 있다 [통념] | — | 화면 페이지에 `overscroll-behavior: contain` |

## 9. 장르별 기본 화면 묶음 (제안) [추정]

### 9.1 원칙

- **틀의 부품, 게임의 내용.** 틀은 화면의 모양(페이지·구역·창·연출의 차례)과 서버 모듈의 상태를 잇는다. 게임은 글(i18n)·그림·색·어느 부품을 쓸지만 고른다. 고르지 않으면 지금과 같다(등불지기·예제의 황금 실행이 같아야 한다: genre-features 5절의 원칙).
- **화면 문장은 모두 i18n.**
- **수집형 화면은 '페이지'다.** 들판 HUD 위에 창을 띄우지 않고, 페이지가 뜨면 HUD(조이스틱·기술·대화·내 정보)를 통째로 감춘다. 페이지 안에서 3D 장면은 배경(대표 캐릭터·탑)으로만 쓴다.
- **폰 세로 먼저.** 모든 페이지를 390×844(아이폰 세로)에서 먼저 잡고, 가로·PC는 넓힌다.
